# To read (important)

both versions are mostly os independent, but some of the code is not. The code in this repository is tested on Linux mainly. If you are using a different OS, you may need to make some changes to the code. but the changes should be minor. If you find any issues, please report them in the issues section of this repository.

# main thing to read

linux terminals are compatible with ANSI escape codes. This means that you can use ANSI escape codes to change the color of the text in the terminal. The code in this repository uses ANSI escape codes to change the color of the text in the terminal. If you are using winsows terminal, you may need to enable ANSI escape codes in the terminal even thogh windows animbyte version do it by default. still even if you face any issue then you can raise issue - i will fix it as soon as possible.
